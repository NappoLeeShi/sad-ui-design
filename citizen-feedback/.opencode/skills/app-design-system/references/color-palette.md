# UI Color Palette & Material Design 3 Mapping

Here is the extracted color palette from the UI interface mapped to the Material Design 3 (MD3) color system.

## Light Theme
| Color Name | Hex Code | Material Design 3 Key |
| ----- | ----- | ----- |
| Dark Red | `#A51B1D` | **Primary** |
| Light Red / Pink | `#FFEBEC` | **Primary Container** |
| Bright Red | `#D13437` | **Secondary** |
| Light Pink / Red | `#FFF0F1` | **Secondary Container** |
| Crimson Red | `#E84D51` | **Tertiary** |
| Soft Light Pink | `#FFF6F7` | **Tertiary Container** |
| Dark Grey | `#858585` | **Neutral / Outline** |
| Light Grey | `#F2F2F2` | **Neutral Variant** |
| Error Red | `#B3261E` | **Error** |
| Light Error Pink | `#F9DEDC` | **Error Container** |
| Pure White | `#FFFFFF` | **Surface / Background** |
| Near Black | `#000000` | **On Surface** |

## Dark Theme
Dark theme is not implemented. You can ignore this section and go to the section below.

## Usage Guide & Recommendations

1. **Buttons & CTAs:**

   * **Primary Action:** Background `#A51B1D` with White text (`#FFFFFF`).

   * **Secondary Action:** White surface (`#FFFFFF`) with Neutral Variant outline (`#F2F2F2`) and Dark Red icon/text (`#A51B1D`).

2. **Typography:**

   * **Headings:** On Surface (`#000000`)

   * **Interactive Links:** Secondary (`#D13437`)

   * **Body/Placeholders:** Neutral (`#858585`)
