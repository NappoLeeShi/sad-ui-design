# Prompt 0 — Project Onboarding and Instruction Discovery

Before implementing anything, familiarize yourself with this repository and its development instructions.

## Tasks

1. Read the root `AGENTS.md` file and any additional `AGENTS.md` files in relevant subdirectories.
2. Identify all mandatory skills, tools, coding conventions, styling rules, and implementation constraints specified in those files.
3. Load and use the required skills before proceeding.
4. Inspect the existing project structure, framework, dependencies, routes, components, assets, and available HTML wireframes.
5. Identify the existing implementation patterns that should be reused.
6. Review the project-specific requirements for the VNeID reporting UI case study.

## Important constraints

- Treat `AGENTS.md` as the primary source of project-specific development instructions.
- Do not ignore, override, or replace its requirements with your own preferences.
- Do not install dependencies or modify project files unnecessarily.
- Do not start implementing pages or changing the existing UI in this step.
- Do not assume that a referenced file exists until you have verified it.
- If instructions conflict or a required skill is unavailable, report the issue instead of silently ignoring it.

## Deliverable

Provide a concise onboarding report containing:

1. Framework and project architecture.
2. Relevant `AGENTS.md` instructions.
3. Required skills identified and loaded.
4. Existing routes, pages, and wireframes found.
5. Existing components and utilities suitable for reuse.
6. Potential technical constraints or conflicts.
7. Recommended implementation sequence.

After presenting the report, stop and wait for the next prompt. Do not begin implementation.
