# Prompt 3 — Implement the Home Page

Implement the Home page as a functional navigation entry point.

### Scope

The only feature that needs to be functional on this page is navigation to the reporting functionality.

### Requirements

1. Follow the existing Home wireframe if available.
2. Preserve the existing visual style and overall page structure.
3. Keep other displayed features as static UI elements if they are part of the reference design.

### Required interaction

- Identify the entry point for the reporting feature, such as a button, card, or service shortcut.
- When the user selects it, navigate to the Feedback Selection page.
- Ensure the navigation target is consistent with the application's routing structure.

### Constraints

- Do not implement unrelated Home features.
- Do not implement notifications, payments, document services, or other VNeID functionality.
- Do not make decorative elements appear functional if they have no implemented behavior.

### Acceptance criteria

- The Home page renders correctly.
- The reporting entry point is clickable.
- Selecting it navigates to Feedback Selection.
- Other unrelated elements remain outside the implementation scope.
